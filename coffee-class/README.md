整個資料夾可複製後離線使用，Wiki 與來源已有可讀 HTML 快照。

- 左右方向鍵、上下頁按鈕與進度條可換頁。
- 第 17 頁有五題可展開答案的測驗。
- 列印按鈕提供全份簡報列印樣式，尚未實際列印驗證。
- sources.html 是逐頁依據，workflow.html 有流程圖，checks/ 有執行報告。
- 學號、系級與姓名請在 submission.md 補齊，再由專案建置腳本重新產生入口。
- 本機 Git 版本歷史位於原專案；交付壓縮包不包含 .git。
