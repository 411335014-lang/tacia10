# 牛奶與奶泡

狀態：已審閱；溫度範圍差異依查證補註
更新日期：2026-11-23

## 學習目標
了解奶泡如何形成、比較拿鐵與卡布奇諾，並辨識常見打奶問題。

## 1. 牛奶為什麼能打出奶泡？
打奶時，蒸氣加熱牛奶，操作位置讓空氣進入；牛奶蛋白質有助於穩定氣泡。脂肪、溫度與操作也會影響質地。
微奶泡（Microfoam）是細緻、均勻、帶有光澤的奶泡，與牛奶融合後能流動，不是表面堆滿大泡泡。

## 2. 拿鐵與卡布奇諾比較
| 項目 | 拿鐵 Latte | 卡布奇諾 Cappuccino |
|---|---|---|
| 基底 | Espresso | Espresso |
| 牛奶 | 通常較多 | 通常相對較少 |
| 奶泡 | 較薄、細緻、融合 | 泡沫口感通常較明顯 |
| 口感 | 奶感較明顯，較柔和 | 咖啡與泡沫存在感較強 |
| 杯量 | 常見較大杯 | 常見較小杯 |

這是常見比較，仍以店內配方為準。卡布奇諾不必一律套用 1:1:1；SCA 2019 文件亦提到杯量與區域差異。

## 3. 打奶泡基本流程
1. 使用乾淨奶缸，倒入符合奶缸容量的冷牛奶。
2. 先排出蒸氣棒內的冷凝水。
3. 尖端靠近液面，適度引入空氣。
4. 調整位置形成穩定旋轉，混合氣泡與液體。
5. 用溫度計觀察，依店內配方、乳品要求與機器手冊停止加熱。
6. 先關閉蒸氣，再移開奶缸，避免噴濺與燙傷。
7. 立即使用專用清潔布擦拭蒸氣棒，再排氣；實際順序與方式依機器手冊。
8. 輕敲並旋轉奶缸，質地均勻後及時倒入咖啡。

原稿的 55–65°C 是練習參考，尚無本輪直接來源支持整段範圍。已讀 GS3 手冊則列約 65–70°C，適用其操作說明，不能直接推成所有牛奶與植物奶的共同標準。因此本講義不指定統一目標溫度。
蒸氣與蒸氣棒會燙傷，不用手直接觸碰尖端，也不以手感代替新手溫度記錄。

## 4. 常見問題
| 問題 | 優先檢查 | 調整方向 |
|---|---|---|
| 大泡泡很多 | 進氣太久、尖端太高 | 減少進氣，改善旋轉與融合 |
| 奶泡太少 | 起始是否幾乎未引入空氣 | 適度增加進氣 |
| 奶泡太厚、難流動 | 是否空氣過多 | 減少進氣量 |
| 粗糙、容易分層 | 溫度、混合與放置時間 | 控制加熱，及時旋轉及使用 |
| 拉花不成形 | 質地與倒奶方式 | 分開練習，不能只歸因於奶泡 |

本表為教學排查建議，須依產品與設備觀察，不保證單一原因。

## 5. 植物奶
植物奶可以起泡，但不同產品的蛋白質、脂肪與配方不同，表現也不同。Barista（咖啡師）版本通常為咖啡調製設計，仍依產品說明與實測調整，不直接沿用所有牛奶設定。本輪未測試特定品牌，不提供品牌間排名。

## 6. 吧台情境
虛構示例：新人做拿鐵，奶泡厚得像一團，缺少流動感。
先檢查進氣是否過久及旋轉是否不足；下一缸先減少進氣，觀察融合與流動性，不為消泡一直加熱。情境與調整步驟為教學設計，非本專案實測。

## 7. 自我測驗與答案
**拿鐵奶泡越厚就越好嗎？**
不是。須符合飲品需要；拿鐵通常重視細緻、融合與流動性。
