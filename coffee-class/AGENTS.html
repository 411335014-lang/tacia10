公主的女僕咖啡教室

本專案屬於 taicai。作業主題為「LLM Wiki：咖啡新手入門知識庫」。

目標與讀者

- 服務咖啡零基礎者與咖啡廳新人，說明製作原理並加入吧台情境。

- 使用繁體中文，重要專有名詞首次出現附英文與白話解釋。

- 頁面類型：主題介紹、飲品比較、常見問題。

- 最終產出：HTML 講義與 HTML 教學簡報。

目錄

- raw/：原始資料、來源登記；已收錄原始資料只讀，不以摘要覆寫。使用者要求修訂時另存版本並保留來歷。

- wiki/：整理後的 Markdown 知識頁；wiki/sources/ 放每篇來源摘要。

- wiki/index.md：知識目錄，列標題、摘要、相對連結與審閱狀態。

- wiki/log.md：依時間追加 ingest、query、lint 紀錄，不改寫舊紀錄。

- lessons/：HTML 講義。製作時於根目錄建立 index.html，列講義標題、摘要及入口。

- slides/：HTML 教學簡報。

- assets/：共用樣式與圖片；現階段不整理圖片，製作簡報時再使用。

- templates/：來源摘要與主題頁模板。

- checks/：檢查清單與實際執行結果。

- 檔名使用英文小寫與連字號，文字使用 UTF-8，站內使用相對連結。

第一階段主題

1. 咖啡風味入門：豆種與產地。比較常見豆種與產區風味，不教烘焙。

2. 咖啡烘焙程度：集中說明淺焙、中焙、深焙與烘焙方法對風味的影響。

3. 義式濃縮萃取：Espresso 原理與變因。

4. 牛奶與奶泡：奶泡原理、拿鐵與卡布奇諾比較。

5. 常見咖啡問題：咖啡因、酸味、苦味。

來源規則

- 至少 ingest 五篇不同的實際來源，不能將五個主題頁當作五篇來源。

- 優先使用專業組織、原始研究與設備製造商教材，辨別產業宣傳與實證主張。

- 每頁末列來源連結即可，不要求逐句引用。來源摘要記錄標題、作者或機構、網址、查閱日期與已讀章節。

- 主題頁連到來源摘要，來源摘要連到 raw 的登記或檔案及原始出處。

- 不捏造來源、日期、數據或閱讀範圍。無法讀取的網頁、未觀看影片與未查證主張標示「待確認」。

- 不整篇複製未獲授權的外部文章；可保存來源登記、合法短摘錄或使用者提供的原始文件。自行整理的摘要明示為摘要。

- 資料互相矛盾時，並列不同說法、來源與適用條件；不能釐清時保留待確認，不擅自消除差異。

- 配方與萃取數值標示單位、條件，說明是起點或範例，不視為所有豆種與設備的通則。

Ingest：一次一篇

1. 先讀目錄、近期 log、本次來源與相關既有頁面。

2. 在 raw/source-register.md 登記來源、日期、已讀範圍與限制，保存原始檔或出處。

3. 依模板建立一篇來源摘要，分清來源主張、教學推論及待確認事項。

4. 整合相關主題頁並增加交叉連結，保留矛盾與適用條件。

5. 更新目錄，依 checks/checklist.md 檢查；修正後重查受影響項目。

6. 追加 log，列來源、變更頁面、實際檢查結果與未解問題。

7. 將本篇摘要、主要變更與待確認事項交給使用者審閱；收到回覆後才 ingest 下一篇，除非使用者明確改為批次。

- 建立資料夾、模板或搜尋候選不算完成 ingest，不可預先記為完成。

Query：回答與累積

- 先查目錄，再讀相關 Wiki 與來源，回答附來源連結。

- Wiki 不足時明說缺口；新增來源依 ingest 流程處理。

- 值得保留的比較、解釋可整合回相關頁面，避免同義重複頁；同步更新目錄與 log。

Lint：檢查迴圈

- 檢查來源可追溯、連結、矛盾、缺漏、重複、過時資訊、初學者可讀性與孤立頁面。

- 結果分為通過、需修正、待確認、未檢查、不適用；未執行不能寫成通過。

- 問題 → 回查來源或修正頁面 → 重查受影響項目 → 記錄結果。無法查證項目保留待確認。

- 每次結果存於 checks/，log 連到該紀錄。

HTML 教學輸出

- 以已審閱 Wiki 為依據，待確認資訊不可作為確定結論。

- Wiki 格式依介紹、比較、FAQ 彈性安排，不強制段落數量。

- HTML 講義一篇一個主題，依序包含標題、學習目標、三個重點、吧台情境、自我測驗與答案、來源、回首頁連結。

- 沿用既有 HTML 結構，所有頁面共用 assets/style.css，採奶油白、咖啡棕與淡紫色。

- 首頁列所有講義並提供簡報入口；講義用 ../index.html 返回首頁。

- 簡報每頁一個核心觀念，附來源與 Wiki 對應，保留重要限制條件。

- 實際產出後檢查首頁往返、手機閱讀、文字溢出與簡報切換；未產出時記為不適用。

Graph 簡報與 Git

- 已確認的大綱保存在 slides/coffee-class/sources.md；變更結構前先取得使用者確認。

- 執行 node scripts/build-slides.js 重新建置，再執行 node scripts/check-slides.js。

- 靜態與模擬 DOM 通過不等於畫面測試通過，受阻須如實記錄。

- 原稿、Wiki、摘要、簡報原始碼、建置結果與檢查紀錄一起提交 Git；不設定遠端或推送，除非使用者要求。
