作業繳交內容

繳交標題：東華 ［學號待填］ 資管［年級待確認］ ［姓名待填］ 咖啡新手入門

1. LLM Wiki 主題與簡短介紹

我的主題是「公主的女僕咖啡教室：咖啡新手入門知識庫」，對象是沒有咖啡基礎的人與咖啡廳新人。內容涵蓋豆種與產地、烘焙程度、義式濃縮、牛奶與奶泡，以及咖啡因和風味迷思。採繁體中文搭配英文專有名詞，並用吧台情境示範。

2. LLM Wiki 成果

已 ingest 五份使用者提供的 Markdown 資料，保留原始稿、來源摘要及五篇整合知識頁。這五份是整理教材，不宣稱五篇獨立學術研究；另外補讀 NCA、SCA、設備手冊與研究，具體出處及限制列在來源摘要。

入口：Wiki 目錄。原始稿位於 raw/，摘要位於 wiki/sources/，規則見 AGENTS.md。

先討論讀者、頁型、語言、引用、矛盾處理、收錄節奏、輸出及檢查，再生成。第一篇與第二篇重複的烘焙內容，也是在討論後調整分工。需求見 需求摘要。

3. 教學 HTML 簡報

開啟 18 頁教學簡報。依五篇 Wiki 的順序編排，包含概念示意、比較、操作步驟、吧台情境與五題可展開答案的測驗。無需安裝套件，資料夾可離線瀏覽。

4. Loop／Graph 設計

流程：取得資料 → 查詢 Wiki → 整理重點與大綱 → 檢查 → 使用者確認 → 產生 HTML → 檢查功能與連結 → 修正再檢查 → 交付及 Git 記錄。

查看流程圖與說明。

大綱有重複或缺漏就回整理節點；成品有錯誤就回製作節點，若涉及結構則回大綱。這樣能在製作前先排除內容分工與來源問題。

5. 一次實際執行與檢查

實際執行報告。已檢查 18 頁順序、換頁與邊界、按鈕焦點下方向鍵、進度條、網址頁碼、五題測驗數、列印答案狀態及離線連結。功能檢查以 Node 模擬 DOM 執行，不等於真瀏覽器測試。

曾發現點過按鈕後方向鍵無效、檢查報告連結缺檔與 Wiki 連結不便攜帶，已修正並重查。

本機檔案被瀏覽器政策阻擋，因此未完成實際瀏覽器、手機畫面及列印驗證；檔案可交由使用者本機瀏覽器開啟，未宣稱已公開部署。

6. 反思

這次最明顯需要反覆調整的是整理重點與大綱檢查節點。例如第一篇一度加入烘焙，和第二篇重複；另有把風味與配方寫得太絕對的情況。

我把「主題分工、引用條件、內容重複」檢查提前到大綱階段，並先確認大綱再生成投影片。成品則新增互動與連結檢查，失敗就回製作節點修正。這是本次觀察，不代表已統計出長期最常失敗的節點。
