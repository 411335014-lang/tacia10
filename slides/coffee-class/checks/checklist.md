# 檢查清單

每次結果另存 checks/，記錄日期、範圍、方法、結果、修正與未解問題。
狀態：通過／需修正／待確認／未檢查／不適用。

- 來源：可由知識頁追溯摘要與原始出處，不引用未讀內容。
- 連結：相對路徑存在；外部來源可讀，受阻記錄限制。
- 矛盾：比對相關來源與頁面，並列不同說法及適用條件。
- 缺漏：涵蓋目標、解釋名詞、數值附單位與條件。
- 重複：相同概念盡量共用頁面，以連結代替複製。
- 過時：核對可能變動的主張，保留查閱日期與更新原因。
- 可讀性：零基礎能理解，有吧台情境，無未解釋縮寫。
- 導覽：目錄完整，正式頁有相關連結與返回目錄入口。
- 審閱：每篇標狀態，等待回覆才 ingest 下一篇。
- HTML：產出後檢查首頁往返、手機閱讀、文字溢出、簡報切換及來源；未產出為不適用。

發現問題 → 修正或回查來源 → 重查受影響項目 → 記錄未解事項。
